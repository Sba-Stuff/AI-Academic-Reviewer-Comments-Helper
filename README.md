# AI Academic Reviewer Comments Helper

This repository contains a tool designed to streamline the process of responding to reviewer comments in academic papers.
<img width="1366" height="768" alt="image" src="https://github.com/user-attachments/assets/95189744-4f78-4aa1-a7ee-204f6a773035" />

## Key Features

*   **Comment Structure:** Prompts for structured feedback on specific points within reviewer comments.
*   **Response Generation:**  Provides responses based on reviewer concerns (e.g., clarity, methodology, etc.).
*   **AI Integration:**  Integration of AI LM Studio based local models to assist in generating initial drafts or refining language.
*   **Saving Comments and Replies:** Allows you to save author replies and reviewer comments for saving time.

## Tech Stack

*   [PHP] - Primary programming language.
*   [LM Studio]:  Downloading and Running Local Models.
*   [Uni Server]: Universal Server to Run Php Code

## Installation Instructions

1.  Clone the repository
2.  Install Software: `LM Studio (Download any Small Size Model based on your PC Specs), Uni Server (To Host and Run Php)`
